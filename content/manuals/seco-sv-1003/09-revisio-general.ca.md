## Revisió general

La revisió general s'ha de realitzar cada 500 hores de funcionament o cada 6 mesos (el que s'escauï first).

### Procediment

1. **Aturada i bloqueig** — Atureu la màquina i bloqueu l'interruptor principal amb pany
2. **Inspecció visual** — Busqueu fuites d'oli, corrosion visible, cables desconnectats
3. **Comprovació de nivell d'oli** — L'oli ha d'estar entre les marques MIN i MAX
4. **Verificació de vibració** — Mesureu la vibració a l'allotjament del motor (màxim 2,8 mm/s)
5. **Prova de funcionament** — Engegueu i observeu sorolls anormals durant 10 minuts

{{< warning type="electric" >}}
**Perill elèctric.** Abans d'obrir el quadre elèctric, assegureu-vos que la màquina està desconnectada de la xarxa i que s'ha dissipat la càrrega dels condensadors (mínim 5 minuts).
{{< /warning >}}

## Taula de verificació

| Element | Estat | Observacions |
|---|---|---|
| Filtre d'aire | □ Net □ Brut |  |
| Refrigeració | □ Correcta □ Insufficient |  |
| Soroll | □ Normal □ Anormal |  |
| Vibració | □ <2,8 mm/s □ >2,8 mm/s |  |
| Fuites | □ Cap □ Presents |  |

{{< note >}}
Registreu totes les observacions al llibre de manteniment. Les anomalias detectades s'han de comunicar immediatament al servei tècnic.
{{< /note >}}
