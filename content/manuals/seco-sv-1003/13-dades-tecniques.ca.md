## Especificacions tècniques

| Paràmetre | SV 1003 D | SV 1005 D |
|---|---|---|
| **Cabal nominal (50 Hz / 60 Hz)** | 3,0 / 3,6 m³/h | 5,0 / 5,6 m³/h |
| **Buit límit** | 150 hPa (mbar) abs. | 150 hPa (mbar) abs. |
| **Potència nominal del motor (50/60 Hz)** | 0,1 / 0,12 kW | 0,14 / 0,16 kW |
| **Velocitat nominal del motor (50/60 Hz)** | 3000 / 3600 min⁻¹ | 3000 / 3600 min⁻¹ |
| **Nivell sonor (EN ISO 2151)** | 59 / 63 dB(A) | 68 / 72 dB(A) |
| **Rang de temperatura ambient** | 0 … 40 °C | 0 … 40 °C |
| **Pressió ambiental** | Pressió atmosfèrica | Pressió atmosfèrica |
| **Pes aproximat** | 5,2 kg | 6,0 kg |

{{< note >}}
Els valors poden variar segons les condicions de funcionament i l'equipament específic. Consulteu la placa identificativa de la vostra màquina per a les dades exactes.
{{< /note >}}
