## Prerequisites

Before starting the installation, verify that the following conditions are met:

- Minimum space: 3m x 2m clear of obstacles
- Power supply: 400V three-phase + neutral + ground
- Compressed air pressure: 6-8 bar (if applicable)
- Ambient temperature: 5°C - 40°C
- Relative humidity: maximum 80% without condensation

{{< note >}}
Installation must be carried out by qualified technical personnel. Improper installation may void the warranty and invalidate the CE declaration.
{{< /note >}}

## Installation Procedure

{{< step number="1" >}}
**Unpacking and verification.** Check that all components are present according to the delivery list. Document any visible damage before signing the delivery note.
{{< /step >}}

{{< step number="2" >}}
**Location and leveling.** Place the machine on a flat and stable surface. Use the leveling feet to ensure a maximum inclination of 0.5°.
{{< /step >}}

{{< step number="3" >}}
**Electrical connection.** Connect the machine to the power grid following the connection panel diagram. Verify the phase sequence before powering on.
{{< /step >}}

{{< step number="4" >}}
**Peripheral connection.** Connect auxiliary systems (extraction, cooling, etc.) according to the diagrams in the annexes chapter.
{{< /step >}}

{{< step number="5" >}}
**Initial verification.** Perform no-load operation tests according to the startup chapter protocol.
{{< /step >}}

{{< warning >}}
Do not put the machine into service until all verifications have been completed and the startup certificate has been signed.
{{< /warning >}}
