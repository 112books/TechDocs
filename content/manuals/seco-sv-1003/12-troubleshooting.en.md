{{< warning type="electric" >}}
**DANGER** — Live cables. Electrical installation work must only be carried out by qualified personnel.
{{< /warning >}}

{{< warning type="thermal" >}}
**CAUTION** — Very hot surfaces. Before carrying out any action that requires touching the machine, allow it to cool down.
{{< /warning >}}

| Problem | Possible Cause | Solution |
|---|---|---|
| **Machine does not start** | Motor does not receive correct voltage | Check power supply |
| | Motor is defective | Repair the machine (contact Busch) |
| **Does not reach normal pressure at suction** | Felt washers (FW) partially obstructed | Replace felt washers |
| | Inlet filter cartridge obstructed | Replace inlet filter cartridge |
| | Vanes stuck | Free or replace vanes |
| | Vanes (VA) worn | Replace vanes |
| **Excessive noise during operation** | Incorrect direction of rotation | Check direction of rotation |
| | Defective bearings | Repair the machine (contact Busch) |
| **Machine overheats** | Insufficient cooling | Remove dust and dirt from the machine |
| | Ambient temperature too high | Observe permitted ambient temperature |
| | Felt washers obstructed | Replace felt washers |
| | Inlet filter obstructed | Replace filter cartridges |

{{< note >}}
For problems not listed in the table, contact your Busch representative.
{{< /note >}}
