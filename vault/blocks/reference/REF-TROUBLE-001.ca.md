| Problema | Possible causa | Solució |
|---|---|---|
| **La màquina no s'engega** | El motor no rep la tensió correcta | Comproveu el subministrament elèctric |
| | El motor està defectuós | Repareu la màquina (contactar amb Busch) |
| **No arriba a la pressió habitual a aspiració** | Arandeles de feltre (FW) parcialment obstruïdes | Canvieu les arandeles de feltre |
| | Cartutx del filtre d'entrada obstruït | Substituïu el cartutx del filtre |
| | Pales encallades | Allibereu les pales o substituïu-les |
| | Pales (VA) gastades | Substituïu les pales |
| **Molt soroll en funcionament** | Sentit de rotació incorrecte | Comproveu el sentit de la rotació |
| | Rodaments defectuosos | Repareu la màquina (contactar amb Busch) |
| **S'escalfa massa** | Refrigeració insuficient | Netegeu la pols i la brutícia de la màquina |
| | Temperatura ambient massa alta | Respecteu la temperatura ambient permesa |
| | Arandeles de feltre obstruïdes | Canvieu les arandeles de feltre |
| | Filtre d'entrada obstruït | Substituïu el cartutx dels filtres |

{{< note >}}
Per a la resolució de problemes que no apareixen a la taula, poseu-vos en contacte amb el vostre representant de Busch.
{{< /note >}}
