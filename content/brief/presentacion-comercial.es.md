# TechDocs — Documentación Técnica Validada

## El Problema

Las pymes industriales pagan **15.000–50.000€ anuales** en licencias de software de documentación (SCHEMA ST4, Paligo, MadCap). A cambio, reciben:

- Dependencia tecnológica permanente
- Costos recurrentes de renovación
- Documentación que no es suya (está en la nube del proveedor)
- Dificultad para cumplir auditorías CE/ISO 9001

## La Solución: TechDocs

Sistema de gestión de documentación técnica basado en **estándares abiertos**:

| Competencia | TechDocs |
|---|---|
| Licencia anual 15-50k€ | **Pago único** |
| Software cerrado | **Código abierto (MIT)** |
| Datos en nube ajena | **Tu servidor/GitHub** |
| Lock-in obligatorio | **Salida libre** |
| PDF básico | **Web + PDF firmado** |
