{{< warning type="electric" >}}
**PELIGRO** — Cables con electricidad. Los trabajos de instalación eléctrica deben ser realizados únicamente por personal cualificado.
{{< /warning >}}

{{< warning type="thermal" >}}
**PRECAUCIÓN** — Superficies muy calientes. Antes de llevar a cabo cualquier acción que requiera tocar la máquina, deje que esta se enfríe.
{{< /warning >}}

| Problema | Posible causa | Solución |
|---|---|---|
| **La máquina no se pone en marcha** | El motor no recibe la tensión correcta | Compruebe el suministro eléctrico |
| | El motor está defectuoso | Repare la máquina (contactar con Busch) |
| **No alcanza la presión habitual en aspiración** | Arandelas de fieltro (FW) parcialmente obstruidas | Cambie las arandelas de fieltro |
| | Cartucho del filtro de entrada obstruido | Sustituya el cartucho del filtro |
| | Paletas atascadas | Libere las paletas o sustitúyalas |
| | Paletas (VA) gastadas | Sustituya las paletas |
| **Mucho ruido en funcionamiento** | Sentido de rotación incorrecto | Compruebe el sentido de la rotación |
| | Rodamientos defectuosos | Repare la máquina (contactar con Busch) |
| **Se calienta demasiado** | Refrigeración insuficiente | Quite polvo y suciedad de la máquina |
| | Temperatura ambiente demasiado alta | Observe la temperatura ambiente permitida |
| | Arandelas de fieltro obstruidas | Cambie las arandelas de fieltro |
| | Filtro de entrada obstruido | Sustituya el cartucho de los filtros |

{{< note >}}
Para la resolución de problemas que no aparecen en la tabla, póngase en contacto con su representante de Busch.
{{< /note >}}
