El projecte

Què és TechDocs?

Un sistema de gestió de documentació tècnica per a empreses que necessiten manuals, certificats i documentació de conformitat — sense pagar 15.000–50.000€ anuals en llicències de SCHEMA ST4, MadCap Flare o Paligo.

TechDocs està basat en estàndards oberts (Markdown, Git, Hugo, Pandoc) i genera tant portals web com PDFs amb metadades legals a partir del mateix contingut. El client és propietari del seu sistema per sempre.

El problema

Per què existeix?

La Directiva de Maquinària 2006/42/CE exigeix que els fabricants de maquinària industrial disposin de documentació tècnica completa: manuals d'operació, manteniment i seguretat en l'idioma del país d'ús, amb traçabilitat de versions i aprovacions. Les auditories ISO 9001 demanen control documental estricte.

Els sistemes actuals del mercat (SCHEMA ST4, MadCap Flare, Paligo) són excel·lents però impagables per a una PYME de 10–200 treballadors. A més, el client queda lligat a un proveïdor amb llicències anuals obligatòries.

TechDocs resol aquesta dicotomia: mateixes funcionalitats, estàndards oberts, sense dependència de proveïdors.

Com funciona

Arquitectura del sistema

TechDocs funciona amb un flux simple però potent:

1. Contingut en Markdown

Els redactors escriuen la documentació en Markdown amb metadades YAML: títol, models aplicables, revisió, aprovador, data d'aprovació, revisió legal. No cal conèixer codi.

2. Edició via web (Decap CMS)

Una interfície web senzilla permet editar continguts sense tocar Git ni línies de comandes. Inclou workflow d'aprovacions: esborrany → revisió → publicat.

3. Publicació automàtica

Cada cop que s'aprova un document, GitHub Actions construeix i desplega automàticament el portal web. El sistema també genera PDFs amb metadades legals (versió, aprovador, data) via Pandoc.

4. Control total via Git

Git registra automàticament qui, quan i què s'ha canviat. Això és exactament el que un auditor CE o ISO necessita veure: traçabilitat completa.

Ingressos recurrents

A diferència dels competidors (on la recurrència és la llicència obligatòria), la recurrència de TechDocs ve del valor afegit:

  • Manteniment i hosting — el sistema funciona sol, però alguns clients prefereixen que algú el vigili
  • Actualitzacions normatives — quan canvia la directiva, cal revisar la documentació
  • Noves versions de producte — cada nou model del client requereix adaptar el sistema
  • Noves traduccions — entrada a nous mercats = nous idiomes
Estat actual

On som ara?

TechDocs té un MVP funcional amb dues demos reals:

Manual Model X100 (demo intern)

  • 3 capítols: Seguretat, Instal·lació, Operació
  • En català (base), amb estructura multiidioma preparada

Manual SECO SV 1003/1005 D (cas real)

  • 8 capítols complets de la documentació original de Busch
  • 4 diagrames tècnics SVG creats per al projecte
  • Disponible en català, castellà i anglès
  • Declaració de conformitat CE inclosa
  • Taula de resolució de problemes completa
  • Referències de peces de recanvi Busch integrades

El sistema està desplegat a 112books.github.io/TechDocs/ amb protecció per contrasenya per a la demo.
