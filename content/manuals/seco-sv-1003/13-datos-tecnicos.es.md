## Especificaciones técnicas

| Parámetro | SV 1003 D | SV 1005 D |
|---|---|---|
| **Caudal nominal (50 Hz / 60 Hz)** | 3,0 / 3,6 m³/h | 5,0 / 5,6 m³/h |
| **Vacío límite** | 150 hPa (mbar) abs. | 150 hPa (mbar) abs. |
| **Potencia nominal del motor (50/60 Hz)** | 0,1 / 0,12 kW | 0,14 / 0,16 kW |
| **Velocidad nominal del motor (50/60 Hz)** | 3000 / 3600 min⁻¹ | 3000 / 3600 min⁻¹ |
| **Nivel sonoro (EN ISO 2151)** | 59 / 63 dB(A) | 68 / 72 dB(A) |
| **Rango de temperatura ambiente** | 0 … 40 °C | 0 … 40 °C |
| **Presión ambiental** | Presión atmosférica | Presión atmosférica |
| **Peso aproximado** | 5,2 kg | 6,0 kg |
