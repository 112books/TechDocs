## Taula de diagnòstic ràpid

Utilitzeu aquesta taula per identificar i resoldre problemes comuns.

| Símptoma | Causa probable | Solució |
|---|---|---|
| La màquina no engega | Sense alimentació elèctrica | Verificar fusibles i tensió |
| | Interruptor d'emergència premut | Gireu el botó per desbloquejar |
| Soroll excessiu | Falta lubricació | Verificar nivell d'oli |
| | Coixinets desgastats | Contactar servei tècnic |
| Pèrdua de buit | Fuites al sistema | Verificar juntes i segells |
| | Filtre d'aire saturat | Substituir filtre |
| Temperatura massa alta | Ventilació obstruïda | Netejar reixes de ventilació |
| | Sobrecàrrega | Reduir càrrega de treball |
| Vibració excessiva | Maquina mal nivellada | Ajustar peus nivelladors |
| | Elements desequilibrats | Contactar servei tècnic |

{{< warning type="electric" >}}
**Perill elèctric.** Abans d'obrir el quadre elèctric per verificar fusibles, desconnecteu l'alimentació i espereu 5 minuts.
{{< /warning >}}

## Codis d'error (pantalla LCD)

| Codi | Descripció | Acció |
|---|---|---|
| E001 | Sobretemperatura motor | Aturar, deixar refredar, verificar ventilació |
| E002 | Sobrecorrent | Verificar càrrega, comprovar kurts |
| E003 | Pressió mínima | Verificar fuites, comprovar bomba |
| E004 | Sensor buit defectuós | Contactar servei tècnic |
| E005 | Comunicació perduda | Reiniciar la màquina |

{{< note >}}
Si l'error persisteix després de seguir les accions indicades, contacteu amb el servei tècnic autoritzat. No intenteu reparacions que requereixin desmuntar la màquina sense autorització.
{{< /note >}}
