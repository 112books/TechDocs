# TechDocs — Documentació Tècnica Validada

## El Problema

Les pymes industrials paguen **15.000–50.000€ anuals** en llicències de software de documentació (SCHEMA ST4, Paligo, MadCap). A canvi, reben:

- Dependència tecnològica permanent
- Costos recurrents de renovació
- Documentació que no és seva (està al núvol del proveïdor)
- Dificultat per complir auditories CE/ISO 9001

## La Solució: TechDocs

Sistema de gestió de documentació tècnica basat en **estàndards oberts**:

| Competició | TechDocs |
|---|---|
| Llicència anual 15-50k€ | **Pagament únic** |
| Software tancat | **Codi obert (MIT)** |
| Dades al núvol aliè | **El teu servidor/GitHub** |
| Lock-in obligatori | **Sortida lliure** |
| PDF bàsic | **Web + PDF signat** |

## Paquets de Preus

### Starter — 2.500–3.500€
**Ideal per a empreses que volen provar**

- Hugo base configurat
- 1 idioma inicial
- Generació de PDF
- Decap CMS (editor web)
- Deploy automàtic
- Tema visual professional

### Professional — 4.500–6.000€  
**La opció més popular**

- **Tot el Starter** +
- 2 idiomes
- Gestió de variants de producte
- Registre d'aprovacions
- Shortcodes tècnics complets
- Cerca estàtica (Pagefind)
- Formació bàsica inclosa

### Legal — 7.000–9.000€
**Per a empreses amb certificació activa**

- **Tot el Professional** +
- PDF signat digitalment (GPG/qualificat)
- Dashboard de traduccions
- Exportació XML (DITA Light)
- Formació completa de l'equip
- 3 mesos d'acompanyament
- Validació per auditor CE
- White-label disponible
